# Документация системы сборки

Этот каталог содержит соглашения, обязательные при изменении PGR_M.

1. [CMAKE.md](CMAKE.md) — структура целей, порядок команд, правила модулей,
   независимость, локальная сборка, диагностика ошибок и тестирование.
2. [CI.md](CI.md) — GitHub Actions, матрица Windows/Linux/macOS, Debug/Release,
   проверки изолированных модулей, поддержка CI и порядок расширения.

## Принцип

Корневой `CMakeLists.txt` описывает общие настройки и подключает каталоги;
каждый модуль определяет только **собственную** цель `pgr_*`;
`app/CMakeLists.txt` выполняет композицию. CI проверяет это на разных ОС.
